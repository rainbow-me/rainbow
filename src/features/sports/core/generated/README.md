# Sports API types

These types are generated by `protobuf-registry`:

- `sports.ts`: shared payloads from `schemas/common/v1/common/sports/sports.proto`
- `requests.ts`: public requests from `schemas/gateways/v1/external/sports/requests.proto`

Edit the relevant schema, then run `make gen_ts` from the registry root. Copy
`schemas/common/gen/v1/ts/common/sports/sports.ts` and
`schemas/gateways/gen/v1/ts/external/sports/requests.ts` into this directory.
